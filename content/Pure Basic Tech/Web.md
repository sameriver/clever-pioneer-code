## 概念
### DNS（Domain Name System）
#### 简介
域名系统：将人类可读域名`www.example.com`转化为IP地址
#### 核心作用
1. 域名解析：example.com->93.184.216.34
2. 服务路由：通过不同记录类型（如MX CNAME）指定服务位置（如邮件服务器 网站服务器）
#### 工作原理
1. 用户输入域名
2. 查询本地缓存：先检查本地DNS缓存是否有记录
3. 递归查询：若无缓存，向递归DNS服务器（如ISP或公共DNS：8.8.8.8）发送请求
4. 分层查询：按层级查询
	1. 根域名服务器->指向.com的顶级域名服务器
	2. 顶级域名服务器->指向example.com的权威域名服务器
	3. 权威域名服务器->返回IP地址
5. IP地址返回用户
